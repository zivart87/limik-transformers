# Рішення та журнал помилок

## 2026-09-25: організація роботи

- AGENTS.md — єдина точка входу, CLAUDE.md — посилання.
- Перевірки обов'язкові за масштабом задачі; короткий звіт замість заборони перевірок.
- Еталони Modular фіксуються по одному в процесі роботи. Масова каталогізація не погоджена.
- Уніфікація CSS головної та генерація nav/footer відкладені користувачем.
- build.js існує, але замінює маркер одноразово та не обробляє footer; не вважати його готовим pipeline.
- Eyebrow: база 32px; FAQ має 20px. Уточнено область дії замість зміни CSS.
- Gold: збережено існуючі icon-link і кнопку Details як винятки. Outline не вводити самовільно, але не видаляти наявні в межах документаційної задачі.
- Контентні абзаци 16px/1.75; поля й примітки мають власні правила.
- Інструменти обираються з доступних; обов'язкового /frontend-design немає.

## Уроки, що залишаються чинними

- Неповний перенос кнопки: перевіряти весь компонент і стани, не тільки колір фону.
- Вузький технічний чекліст пропускає блоки: оглядати всю сторінку.
- Каскад .pt-sidebar-form p перебиває простий клас примітки/телефону: використовувати селектор з батьківським класом і явні відступи.
- overflow:hidden і transform для каруселі мають бути на різних вкладених елементах.
- Footer через outerHTML замінює вузол: не кешувати старий placeholder для обчислення видимості.
- Спільний CSS не впливає на головну з inline-стилями.
