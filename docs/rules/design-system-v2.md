- Контейнер: `--gutter: max(40px, calc((100vw - 1360px) / 2 + 40px))`; ≤768px — 24px.

## 5. Заокруглення

`--radius: 6px`, 4 рівні + 1 виняток:
- `--r-sm` ≈4px (×0.6) — теги, бейджі;
- `--r-md` 6px (×1) — кнопки `.btn`, поля, плитки вибору;
- `--r-lg` ≈8px (×1.4) — картки, фото, біла плашка характеристик;
- `--r-xl` 12px (×2) — великі плашки;
- **виняток:** квадрат icon-link — 4px.
Не заокруглюються: full-bleed hero, фони секцій, панель цифр зі зрізаним кутом, лінії.

## 7. Анімації

- **Add project details (рішення користувача 2026-10-02):** розкриття 0.4s, закриття 0.3s ease-out із плавною зміною висоти та opacity, за темпом FAQ. Плюс повертається синхронно; повторний клік плавно змінює напрям. Підтримуються клавіатура й відкриття через CTA schedule/fit; без JS/Web Animations лишається нативний `<details>`. Закриті поля мають inert; після відкриття висота природна, зокрема при зміні ширини чи продукту.

- Hero — як на головній: плавна поява фону (`bgEnter`, 1.4s), поява слів заголовка (`wordReveal`, 0.8s), виїзд lead і кнопок (`heroUp`, 0.7s, затримка 0.55s); градієнт нерухомий.
- Стрічка логотипів — безперервна; FAQ — висота 0.4s/0.3s ease-out (патерн Modulabs); картки Configurations — width 0.5s; рендер, опис і Configure — opacity 0.5s ease після затримки 0.3s (попередній плавний патерн збережено; затримку скорочено з 0.5s за запитом користувача); таймлайн — заливка лінії 2.4s; поява карток при прокрутці по черзі.
- Інтерактивні анімації **не вимикати** через `prefers-reduced-motion` (у користувача вимкнено «Ефекти анімації» в Windows); допустимо лише сповільнення безкінечних рухів.
