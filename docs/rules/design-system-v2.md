Затверджено користувачем 2026-09-27. Джерело правди за розмірами, відступами й поведінкою — прототип `docs/prototypes/modular-dc-wireframe.html`; за кольорами — таблиця нижче (превʼю кольорів погоджено 2026-09-27).

**Статус і межі.**
- Діє для сторінки `modular-ai-data-centers/` і для всіх сторінок, які переробляються на нову систему. Решта сайту поки живе за `design-system.md` (v1), доки її не перероблять.
- Меню (`nav.html`) і футер (`footer.html`) — спільні файли, у межах v2 не змінюються.
- Нові значення, кольори, радіуси чи відступи поза цим файлом не вводити без рішення користувача. Детальні описи компонентів Modular — `components.md` (розділи «Modular AI Data Centers — …»), форми — `forms.md`, FAQ і SEO — `seo.md`. Якщо ці файли суперечать цьому — діє цей файл, а суперечність виправити.
- Стилі v2 підключаються лише на сторінках v2 і скоупляться під клас сторінки (`.mdc-page`), щоб не зачепити сторінки v1 через спільний `limik.css`.

Правила:
- Один акцентний синій (`--blue` на світлому, `--blue-lt` на темному). Інших відтінків синього не вводити.
- `--blue-lt` для дрібного тексту — тільки на `--navy-dark`; на `--navy-mid` контраст 4.31:1, нижче норми.
- Жовтий — лише CTA-кнопка й квадрат icon-link. **Відкрите питання (2026-09-27):** квадрат icon-link поки жовтий; альтернатива — синій з білою стрілкою, щоб жовтими лишились лише CTA. Вирішити після перегляду живої сторінки.
- Фони секцій чергуються: білий / світлий / темний; дві сусідні з однаковим фоном — один відступ (`.flush-top`).
- Контраст перевіряти формулою WCAG: текст ≥4.5:1 (великий ≥3:1), межі інтерактивних елементів і стани ≥3:1.

## 3. Сітка

- Контейнер: `--gutter: max(40px, calc((100vw - 1360px) / 2 + 40px))`; ≤768px — 24px.
- Hero: 60px / 40px / 24px (відкрите питання п.9: вирівняти по контейнеру 40px чи лишити 60px).
- Шапка секції (2:1): h2 зліва, вступ справа до 36ch, `align-items: start`; ≤991px — одна колонка.
- У grid/flex-нащадків `min-width: 0`; жодного горизонтального скролу на 390/360px.

## 4. Вертикальні відступи

| Між чим | Відступ |
|---|---|
| Секції | 120 / 80 / 60px (десктоп / ≤991 / ≤768) |
| Самостійні підблоки однієї секції (`.sub-gap`) | 80 / 64 / 48px |
| Шапка секції → контент | 64px (≤991: 48px) |
| Зображення → пов'язаний текст; кнопка → зображення | 48px |
| Останній текст → кнопка; панель цифр → зображення | 40px |
| Eyebrow → h2 | 32px (FAQ 20px) |
| Hero: текстовий блок → нижня лінія | 88px (≤991: 64px) |
| Рядки форми | 24px; підпис → поле 10px; колонки форми 18px |

Правило: що самостійніший підблок, то більший відступ; нових значень не вводити.

## 5. Заокруглення

`--radius: 6px`, 4 рівні + 1 виняток:
- `--r-sm` ≈4px (×0.6) — теги, бейджі;
- `--r-md` 6px (×1) — кнопки `.btn`, поля, плитки вибору;
- `--r-lg` ≈8px (×1.4) — картки, фото, біла плашка характеристик;
- `--r-xl` 12px (×2) — великі плашки;
- **виняток:** квадрат icon-link — 4px.
Не заокруглюються: full-bleed hero, фони секцій, панель цифр зі зрізаним кутом, лінії.

## 6. Компоненти

- **Кнопка `.btn` (CTA):** висота 52px, padding 0 28px, 13px/700 uppercase, `--v2-cta`, радіус 6px. На сторінці — лише для переходу до форми заявки; до 600px у формі й hero на всю ширину. (На v1 — 48px/14px; стандартом для нових сторінок стає v2.)
- **Icon-link:** квадрат 36×36, радіус 4px, стрілка ~14px, проміжок до тексту 16px, текст 13px/800 uppercase; від останнього абзацу до icon-link 40px. Для переходів і допоміжних дій.
- **Контекстне посилання в тексті:** `--v2-accent`, підкреслення, offset 2px, hover `--navy-dark`.
- **Картки:** білі на світлому / `--v2-card-dark` з рамкою `--v2-line-dark` на темному; padding 28–32px; радіус `--r-lg`.
- **Вкладки (FAQ):** REM 11px/700 uppercase, tracking .1em; неактивна `--v2-text-inactive`, активна `--v2-text` + лінія 2px `--v2-accent`.
- **FAQ, форма, специфікації, таймлайн, конфігурації, sticky Platform** — докладно в `components.md` / `forms.md` / `seo.md`.

## 7. Анімації

- Hero — як на головній: плавна поява фону (`bgEnter`, 1.4s), поява слів заголовка (`wordReveal`, 0.8s), виїзд lead і кнопок (`heroUp`, 0.7s, затримка 0.55s); градієнт нерухомий.
- Стрічка логотипів — безперервна; FAQ — висота 0.4s/0.3s ease-out (патерн Modulabs); картки Configurations — width 0.5s; таймлайн — заливка лінії 2.4s; поява карток при прокрутці по черзі.
- Інтерактивні анімації **не вимикати** через `prefers-reduced-motion` (у користувача вимкнено «Ефекти анімації» в Windows); допустимо лише сповільнення безкінечних рухів.

## 8. Контент і SEO (коротко)

- Значущий текст — у сирому HTML; закриті вкладки/відповіді ховаються, не видаляються.
- FAQPage JSON-LD — лише підтверджені питання вкладок 1–2, дослівно (див. `seo.md`).
- Жовті мітки `.tbc` і непідтверджені питання на продакшн не потрапляють.
- Медіа — лише з `assets/`; фото/іконки не генерувати AI (Heroicons, Flaticon, сток Magnific).
